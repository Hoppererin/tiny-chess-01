# tiny-chess-01 — a 4 KB chess engine

A compact alpha-beta chess engine in Python, written for the make.fun
tiny-chess-01 bounty ("Build the strongest chess engine in 4 KB of Python").

`main.py` is the whole engine (≤ 4,096 bytes): a `#coding:l1` stub that
unpacks and runs the readable source in `engine.py` (packed with
`node cli/makefun.mjs compress`). It plays the house gauntlet through the
trial environment over HTTP — no model calls, no network beyond the env.

Engine: 0x88 board, transposition table with Zobrist hashing, quiescence
search, MVV-LVA + killer + history move ordering, null-move pruning and
piece-square evaluation. It searches to a fixed node budget per move, so
every trial replays deterministically.
